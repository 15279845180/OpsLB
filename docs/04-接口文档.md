# OpsLB 接口文档（V2.5）

## 一、OpenSIPS → Go 内部接口

> 以下接口由 OpenSIPS 通过内网调用，无需 JWT 认证。
> Go API 基地址: `http://127.0.0.1:8080`

---

### 1.1 一体化分配（核心接口）

**POST** `/api/call/allocate`

一次 HTTP 完成：入局授权 + 路由选择 + 出局授权

**请求参数：**

```json
{
    "call_id":    "abc123@192.168.1.168",   // SIP Call-ID（必填）
    "caller":     "13800138000",            // 主叫号码
    "called":     "13900139000",            // 被叫号码
    "inbound_ip": "10.0.0.1"               // 入局源IP（必填）
}
```

**成功响应：**

```json
{
    "allowed":            true,
    "inbound_id":         1,
    "gateway_id":         3,
    "gateway_ip":         "192.168.1.100",
    "gateway_port":       "5060",
    "protocol":           "udp",
    "current_concurrent": 42
}
```

**失败响应（各种场景）：**

```json
// IP 不在白名单
{"allowed": false, "error_code": -4, "reason": "IP not authorized"}

// 入局并发已满
{"allowed": false, "error_code": -3, "reason": "Inbound concurrent full"}

// 所有网关不可用（CPS限制）
{"allowed": false, "error_code": -1, "reason": "All gateways at capacity"}

// 所有网关不可用（并发满）
{"allowed": false, "error_code": -3, "reason": "All gateways at capacity"}

// 出局并发已满
{"allowed": false, "error_code": -3, "reason": "Outbound concurrent full"}

// 重复INVITE被拒绝（call_id已释放）
{"allowed": false, "error_code": -5, "reason": "Call already released"}
```

**错误码说明：**

| ErrorCode | 含义 | 应返回的SIP状态码 |
|-----------|------|-------------------|
| -1 | CPS超限 | 503 Service Unavailable |
| -2 | 无可用网关 | 503 Service Unavailable |
| -3 | 并发已满 | 503 Service Unavailable |
| -4 | IP未授权 | 403 Forbidden |
| -5 | 通话记录异常 | 503 Service Unavailable |

**OpenSIPS 调用方式：**

```opensips
$var(body) = "{\"call_id\":\"" + $ci + "\",\"caller\":\"" + $fU + "\",\"called\":\"" + $rU + "\",\"inbound_ip\":\"" + $si + "\"}";
async(rest_post("http://127.0.0.1:8080/api/call/allocate",
                $var(body), "application/json", $var(resp_body)),
      RESUME_ALLOCATE);
```

### 1.2 释放并发

**POST** `/api/call/release`

释放入局 + 出局并发计数器，更新话单状态。

**请求参数：**

```json
{
    "call_id":     "abc123@192.168.1.168",  // SIP Call-ID（必填）
    "reason":      "bye",                   // bye/cancel/failed
    "status_code": 200                      // 仅在 reason="failed" 时传入
}
```

**响应：**

```json
{
    "released":          true,
    "inbound_released":  true,
    "outbound_released": true
}
```

**OpenSIPS 调用示例：**

```opensips
# BYE 释放
$var(body) = "{\"call_id\":\"" + $var(c_cid) + "\",\"reason\":\"bye\"}";
rest_post("http://127.0.0.1:8080/api/call/release", $var(body), ...);

# CANCEL 释放
$var(body) = "{\"call_id\":\"" + $var(c_cid) + "\",\"reason\":\"cancel\"}";
rest_post("http://127.0.0.1:8080/api/call/release", $var(body), ...);

# failure 释放
$var(body) = "{\"call_id\":\"" + $var(f_cid) + "\",\"reason\":\"failed\",\"status_code\":" + $var(status) + "}";
rest_post("http://127.0.0.1:8080/api/call/release", $var(body), ...);
```

### 1.3 SIP 事件上报

**POST** `/api/route/event`

用于话单状态更新（event 接口不操作并发计数器）。

**请求参数：**

```json
{
    "type":        "answer",                // invite/answer/bye/cancel/failed
    "call_id":     "abc123@192.168.1.168",  // SIP Call-ID（必填）
    "inbound_ip":  "10.0.0.1",             // invite 时传入
    "caller_number": "13800138000",         // invite 时传入
    "called_number": "13900139000",         // invite 时传入
    "gateway_id":  3,                       // 出局网关ID
    "inbound_id":  1,                       // 入局网关ID
    "status_code": 200                      // answer/failed 时传入
}
```

**事件类型说明：**

| type | 触发时机 | 操作 |
|------|---------|------|
| invite | INVITE 到达 | 仅记录日志（话单由 allocate 创建）|
| answer | 200 OK | 更新 answer_time, status_code=200 |
| bye | BYE 挂断 | 更新 end_time, talk_duration |
| cancel | CANCEL 取消 | 更新 status_code=487, end_time |
| failed | 4xx/5xx/6xx | 更新 status_code, end_time |

**OpenSIPS 调用示例：**

```opensips
# onreply_route 中上报 failure
$var(body) = "{\"type\":\"failed\",\"call_id\":\"" + $ci + "\",\"status_code\":" + $rs + "}";
rest_post("http://127.0.0.1:8080/api/route/event", $var(body), ...);
```

## 二、管理接口（需要 JWT 认证）

> 所有管理接口需要在 Header 中携带 `Authorization: Bearer <token>`

### 2.1 认证

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/login` | 登录获取 token |
| POST | `/api/change-password` | 修改密码 |

### 2.2 入局网关

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/inbound` | 获取所有入局网关 |
| GET | `/api/inbound/:id` | 获取单个入局网关 |
| POST | `/api/inbound` | 创建入局网关 |
| PUT | `/api/inbound/:id` | 更新入局网关 |
| DELETE | `/api/inbound/:id` | 删除入局网关 |
| POST | `/api/inbound/reload` | 刷新OpenSIPS白名单 |

### 2.3 出局网关

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/outbound` | 获取所有出局网关 |
| GET | `/api/outbound/:id` | 获取单个出局网关 |
| POST | `/api/outbound` | 创建出局网关 |
| PUT | `/api/outbound/:id` | 更新出局网关 |
| DELETE | `/api/outbound/:id` | 删除出局网关 |
| POST | `/api/outbound/batch-status` | 批量更新网关状态 |

### 2.4 话单查询

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/call-records` | 查询话单列表（支持分页筛选） |
| GET | `/api/call-records/export` | 导出CSV |

### 2.5 仪表盘

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/dashboard/stats` | 获取统计数据 |
| GET | `/api/dashboard/ws` | WebSocket实时推送 |

### 2.6 系统设置

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/settings` | 获取系统配置 |
| PUT | `/api/settings` | 更新系统配置 |

## 三、数据模型

### 3.1 入局网关 (InboundGateway)

```json
{
    "id":             1,
    "name":           "上海电信SIP中继",
    "ips":            "10.0.0.1\n10.0.0.2",
    "max_concurrent": 500,
    "current_calls":  123,
    "status":         1,
    "description":    "上海电信主中继"
}
```

### 3.2 出局网关 (OutboundGateway)

```json
{
    "id":              3,
    "name":            "北京移动网关",
    "ip":              "192.168.1.100",
    "port":            5060,
    "protocol":        "udp",
    "priority":        1,
    "weight":          5,
    "max_concurrent":  200,
    "max_cps":         50,
    "status":          1,
    "current_calls":   42
}
```

**字段说明：**
- `priority`: 优先级，数字越小优先级越高，同优先级按权重分配
- `weight`: 权重 1-100，同优先级内按权重比例分配流量
- `max_cps`: 每秒最大呼叫数，0 表示不限制
