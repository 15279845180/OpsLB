# OpsLB 部署指南（V2.5）

## 一、环境要求

| 组件 | 最低版本 | 已验证版本 |
|------|---------|-----------|
| OS | Ubuntu 20.04+ / CentOS 7+ | Ubuntu 24.04.02 |
| OpenSIPS | 3.6.4 | 3.6.4 |
| Go | 1.21+ | 1.26.2 |
| Redis | 6.x+ | 8.0 |
| MySQL | 8.0+ | 8.0 |
| Nginx | 1.20+（可选反向代理） | 1.26 |

> **已验证环境：** Ubuntu 24.04.02 + Go 1.26.2 + Redis 8.0 + MySQL 8.0 + Nginx 1.26 + OpenSIPS 3.6.4
>
> Go 1.26.2 和 Redis 8.0 均向下兼容，新版本可直接使用。

## 二、MySQL 部署

### 2.1 安装

```bash
# Ubuntu 24.04
apt install -y mysql-server
systemctl enable mysql
systemctl start mysql

# CentOS 7
yum install -y mysql-server
systemctl enable mysqld
systemctl start mysqld
```

### 2.2 创建数据库

```sql
CREATE DATABASE opslb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'OpsLB'@'127.0.0.1' IDENTIFIED BY '你的密码';
GRANT ALL PRIVILEGES ON opslb.* TO 'OpsLB'@'127.0.0.1';
FLUSH PRIVILEGES;
```

### 2.2 初始化表结构

执行 `docs/sql/` 下的 SQL 脚本：
- `01-create-database.sql`
- `02-create-tables.sql`
- `03-init-data.sql`

### 2.3 话单分表

话单表按日期自动分表（`cdr_call_20260511`），Go 启动时自动创建当天表，每天 23:50 预创建次日表。

## 三、Redis 部署

```bash
# Ubuntu 24.04
apt install -y redis-server
systemctl enable redis-server
systemctl start redis-server

# CentOS 7
yum install -y redis
systemctl enable redis
systemctl start redis

# 验证
redis-cli ping  # 应返回 PONG
```

> **版本兼容：** Redis 8.0 向下兼容所有 Redis 6.x/7.x 命令，go-redis v9 客户端已验证通过。

**内存建议**：并发计数器数据量极小，2GB 内存足够。

## 四、OpenSIPS 部署

### 4.1 安装

```bash
# Ubuntu 24.04（推荐添加官方源获取 3.6.4）
apt install -y gnupg2 wget
wget -O - https://apt.opensips.org/opensips-org.gpg | gpg --dearmor -o /usr/share/keyrings/opensips-org.gpg
echo "deb [signed-by=/usr/share/keyrings/opensips-org.gpg] https://apt.opensips.org noble 3.6-releases" > /etc/apt/sources.list.d/opensips.list
apt update
apt install -y opensips opensips-mysql-module opensips-restclient-module opensips-json-module

# CentOS 7
yum install -y epel-release
yum install -y opensips opensips-mysql opensips-restclient opensips-json

# 确认版本
opensips -V  # 应为 3.6.4
```

> **注意：** Ubuntu 24.04 发行代号为 `noble`，OpenSIPS 官方源需要正确指定。

### 4.2 加载模块清单

确保以下模块已编译安装：
- `db_mysql.so` - MySQL 连接
- `permissions.so` - IP 白名单
- `rest_client.so` - HTTP 异步调用
- `json.so` - JSON 解析
- `dialog.so` - Dialog 状态跟踪
- `tm.so` - 事务管理
- `sl.so` - 无状态回复
- `rr.so` - Record-Route
- `sipmsgops.so` - SIP 消息操作

### 4.3 配置文件

将项目根目录的 `opensips.cfg` 复制到 `/etc/opensips/opensips.cfg`：

```bash
cp opensips.cfg /etc/opensips/opensips.cfg
```

**必须修改的配置项**（`opensips.cfg` 中）：
- `socket=` 绑定的 IP 地址（默认 192.168.1.168）
- MySQL 连接密码（`modparam("permissions", "db_url", ...)`）
- Go API 地址（`$var(go_api_base)` 默认 `http://127.0.0.1:8080/api/call`）

### 4.4 启动

```bash
# 生产环境启动参数
opensips -m 2048 -M 256 -f /etc/opensips/opensips.cfg

# 调试模式（前台运行）
opensips -m 2048 -M 256 -E -f /etc/opensips/opensips.cfg
```

**参数说明：**
- `-m 2048`: 共享内存 2048MB
- `-M 256`: 私有内存 256MB
- `-E`: 前台运行（调试用）
- `-f`: 指定配置文件

## 五、Go 后端部署

### 5.1 编译

```bash
cd /opt/OpsLB
go build -o OpsLB.exe .
```

### 5.2 配置

编辑 `config/config.go` 或使用环境变量（推荐）。

**关键配置：**

```yaml
server:
  port: "8080"

mysql:
  host: "127.0.0.1"
  port: "3306"
  user: "OpsLB"
  password: "你的密码"
  database: "opslb"

redis:
  host: "127.0.0.1"
  port: "6379"
  password: ""
  db: 0

jwt:
  secret: "你的JWT密钥"
```

### 5.3 启动

```bash
# 前台运行
./OpsLB.exe

# Systemd 服务
cat > /etc/systemd/system/opslb.service << 'EOF'
[Unit]
Description=OpsLB Go Backend
After=network.target mysql.service redis.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/OpsLB
ExecStart=/opt/OpsLB/OpsLB.exe
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable opslb
systemctl start opslb
```

### 5.4 健康检查

```bash
# 登录接口（确认服务正常）
curl -X POST http://127.0.0.1:8080/api/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 仪表盘统计
curl http://127.0.0.1:8080/api/dashboard/stats \
  -H "Authorization: Bearer <token>"
```

## 八、启动顺序

```
1. MySQL     (systemctl start mysql)
2. Redis     (systemctl start redis-server)
3. Go 后端   (systemctl start opslb)
4. OpenSIPS  (systemctl start opensips)
5. Nginx     (systemctl start nginx)  ← 可选
```

> **服务名差异：** Ubuntu 下 Redis 服务名为 `redis-server`，MySQL 为 `mysql`；CentOS 下分别为 `redis` 和 `mysqld`。

## 六、Nginx 反向代理（可选）

如果需要在公网访问管理页面，使用 Nginx 反向代理 Go 后端：

```bash
# 安装
apt install -y nginx

# 配置
cat > /etc/nginx/sites-available/opslb << 'EOF'
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # WebSocket 支持
    location /api/dashboard/ws {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
EOF

ln -s /etc/nginx/sites-available/opslb /etc/nginx/sites-enabled/
rm /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

## 七、防火墙配置

```bash
# === Ubuntu 24.04 (ufw) ===
ufw allow 5060/udp
ufw allow 5060/tcp
ufw allow from 127.0.0.1 to any port 8080 proto tcp
ufw allow 80/tcp        # Nginx
ufw enable

# === CentOS 7 (firewalld) ===
firewall-cmd --add-port=5060/udp --permanent
firewall-cmd --add-port=5060/tcp --permanent
firewall-cmd --add-rich-rule='rule family="ipv4" source address="127.0.0.1" port protocol="tcp" port="8080" accept' --permanent
firewall-cmd --reload
```

## 九、验证部署

```bash
# 1. 确认 Go 服务正常
curl http://127.0.0.1:8080/api/login

# 2. 确认 OpenSIPS 监听
ss -tlnp | grep 5060

# 3. 发送 OPTIONS 探测
sipcmd -u test -P udp://127.0.0.1:5060

# 4. 查看 OpenSIPS 日志
# Ubuntu: tail -f /var/log/syslog | grep opensips
# CentOS: tail -f /var/log/messages | grep opensips
```

## 十、常见问题

### 10.1 OpenSIPS 启动失败

```bash
# 检查配置语法
opensips -C -f /etc/opensips/opensips.cfg

# 检查模块是否安装
ls /usr/local/lib64/opensips/modules/
```

### 10.2 Go 连接 Redis 失败

```bash
# 确认 Redis 监听
redis-cli ping

# 检查防火墙
ss -tlnp | grep 6379
```

### 10.3 话单表不存在

Go 启动时会自动创建当天话单表，如果失败检查 MySQL 权限：
```sql
SHOW GRANTS FOR 'OpsLB'@'127.0.0.1';
-- 需要 CREATE TABLE 权限
```
